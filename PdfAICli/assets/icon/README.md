# Uygulama ikonu – ana kaynak

Bu klasöre **1024×1024 px** ana ikonunuzu (PNG) koyun.

- **Önerilen örnek (AI tahlil temalı):** `tahlil_analizi_ai_icon_1024.png` – yapay zeka + tahlil/rapor teması.
- Alternatif: `tahlil_analizi_icon_1024.png` – genel tahlil temalı.
- [appicon.co](https://appicon.co) veya [makeappicon.com](https://makeappicon.com) ile bu dosyadan Android + iOS tüm boyutları üretin.
- Detaylı adımlar: `docs/APP_ICON_TAHLIL_ANALIZI.md`
